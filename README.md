# Checklist Situacional (CME) — 2026

Ferramenta web simples para apoiar a gestão e aplicação de checklist situacional para CME (Central de Material e Esterilização).

## Como usar
1. Baixe o repositório ou acesse pelo GitHub Pages (se estiver publicado).
2. Abra o arquivo `index.html` no navegador (Chrome/Edge).

## Estrutura do projeto
- `index.html` — Interface principal
- `app.js` — Lógica do aplicativo
- `questions.js` — Perguntas/itens do checklist
